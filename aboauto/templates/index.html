What is this? aboauto in a nutshell

aboauto is a semi account manager for Roblox on Linux. It keeps your accounts in an encrypted local SQLite database (~/.local/share/aboauto/aboauto.db), lets you launch any number of Roblox clients at once (Multi Instance), and tracks every running client so you can stop or restart them (Instance Manager).

Roblox has no official Linux client and limits one instance per Wine prefix, so aboauto gives each launch its own isolated WINEPREFIX. You still need Wine installed and a Roblox install (typically ~/.wine/drive_c/Program Files (x86)/Roblox/…/RobloxPlayerBeta.exe).

Settings paths & behaviour

Wine mode: install Wine (sudo apt install wine) and point the exe path at your Windows Roblox install. Sober mode: install Sober (flatpak install flathub org.vinegarhq.Sober); aboauto launches flatpak run org.vinegarhq.Sober and you log in inside Sober. Credentials are encrypted with Fernet and stored in ~/.local/share/aboauto/key.bin + aboauto.db. Back up key.bin or you lose access to saved passwords/cookies.
